Whistler Studio -- getting started

Singing with Microsoft Sam, Mike and Mary, note by note.

Running it

Windows. Unzip the folder anywhere and run WhistlerStudio.exe inside it.
Keep the folder together. The first time, SmartScreen will stop it: choose
"More info", then "Run anyway".

macOS. Unzip and put Whistler Studio.app where you want it. Before it will
open, run this in Terminal:

    xattr -c "/Applications/Whistler Studio.app"

The voices

Sam, Mike and Mary are Microsoft's, and their files are not part of this
program. They come with Windows XP and with the SAPI 5.1 voices:

    Sam.spd and Sam.sdf      Sam (and the same two files for Mike and Mary)
    LTTS1033.LXA             the dictionary
    r1033tts.LXA             the letter-to-sound rules

If Windows has them installed, they are found without asking. If not, the
program says what is missing and asks for the folder they are in, and
remembers it. You can also put them in a folder called voices beside the
program.

Making a sound

The window has three things: a list of tracks, a list of notes, and a
Messages box at the bottom that tells you what happened. Tab moves between
them, and F6 jumps between the two lists.

You start with one empty track. To put something in it:

1. Press Ctrl+W. Type daisy and press Enter to look it up, then Enter again
   to add it.
2. Press Ctrl+P to play.

Sam's dictionary divides a word into syllables, so daisy goes on two notes,
dai and sy. To sing a word on fewer notes, change "Notes to use" in the same
dialog. A hyphen in what you type -- dai-sy -- also says where it divides.

Add more words the same way. Each one goes in after the note you are on, so
arrow down to the end first if you want it there.

Changing what you have

Move to a note with the arrow keys. Then:

- Alt+Up and Alt+Down move it a semitone.
- Alt+Right and Alt+Left make it a sixteenth note longer or shorter.
- Ctrl+H plays that note on its own, which is quicker than playing the
  song.
- Enter opens it: the phonemes, the pitch, the length, and the pitch bend.
- Delete removes it.

Pitches can be typed as names -- C4, F#3, Bb5 -- or as numbers. Phonemes
are Sam's, in lower case with spaces between them, like d ey 1. The 1 after
a vowel means it is stressed. The Insert phoneme button lists all forty,
each with a word it is heard in.

Ctrl+R puts in a rest. Rests are worth using: they end a phrase, and the
program treats each phrase separately, so silences come out the length you
asked for.

Press Space to play from the note you are on, and Space again to stop.

If you want to hear each change as you make it, turn on Ctrl+Shift+P. Then
nudging a pitch or a length plays that note once you stop.

Voices

Press F6 to get to the tracks list, then Enter on the track. That dialog
has the voice, the volume, the pan, and the reverb for that part, and the
voice controls: vibrato, portamento, detune, and an effect -- a hall, a
stadium, a whisper, or one of the RoboSoft robots.

Ctrl+T adds another track, with its own voice and its own notes. M and
S on a track mute and solo it.

The song as a whole

Ctrl+comma opens the song settings: the tempo, the time signature, how
long the consonants are, the reverb, and the voice controls that every track
follows unless you give it its own.

Saving, importing and exporting

- Ctrl+S saves the song as a .wst file, and Ctrl+O opens one.
- Ctrl+Shift+I imports a VocalWriter Studio project (.vws). Its phonemes
  are changed into Sam's, and every part is sung by Sam until you choose
  another voice. Save it afterwards to keep it as a .wst.
- Ctrl+I imports a MIDI file. If it has no words in it, every note is
  given aa so you can hear the tune before typing anything.
- Ctrl+Shift+S writes the whole song to a WAV.
- Ctrl+Shift+T writes one WAV per track.

From a script

There is a second program in the Windows folder, whistler.exe, which is
this one without the window. Give it a song and somewhere to put the audio:

    whistler song.wst -o song.wav
    whistler tune.mid -o tune.wav --voice Mary --tempo 96
    whistler old.vws --save new.wst
    whistler song.wst --tracks stems

A MIDI file or a VocalWriter Studio project is imported the way the File
menu imports it. --tempo, --voice, --consonants, --reverb, --from and
--track change how it is sung without changing the file; --save writes it
out as a song; --list-voices names the voices and --pronounce says what the
dictionary makes of a word. whistler --help lists the lot.

On a Mac it is the program inside the bundle:

    "/Applications/Whistler Studio.app/Contents/MacOS/WhistlerStudio" song.wst -o song.wav

If it stops working

The song is copied automatically a couple of seconds after you change it. If
the program closes on its own, it offers that copy back the next time you
start it. The copy is called recovery.wst and lives in
%APPDATA%\Whistler Studio on Windows, or
~/Library/Application Support/Whistler Studio on a Mac.

When it starts it prints a line in the Messages box that begins "this is
build". Quote that if you report a problem.

The keys worth remembering

    Ctrl+W    add a word          Space     play from here, or stop
    Ctrl+N    add a note          Ctrl+P    play from the start
    Ctrl+R    add a rest          Ctrl+H    hear one note
    Enter     edit                Ctrl+.    stop
    Delete    remove              F6        tracks list / notes list
    Alt+Up/Down     pitch         Ctrl+T    add a track
    Alt+Left/Right  length        Ctrl+,    song settings

F1 reads the full list into the Messages box.

The voices are Microsoft Sam, Mike and Mary, and are Microsoft's. The engine
that sings them is KamiKitsune420's reconstruction of Microsoft's, at
https://github.com/KamiKitsune420/ms-sam-mike-mary-decomp. The editor began
as VocalWriter Studio, https://github.com/masonasons/vocalwriter, and is at
https://github.com/RetroBunn/ms-sam-mike-mary-singing.
